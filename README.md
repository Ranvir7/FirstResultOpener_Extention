## 📖 About

FirstResultOpener Extension is a productivity-focused browser extension that automatically opens the first organic search result when the activation key is pressed on supported search engine result pages.

Instead of manually selecting the first result after every search, users can navigate directly to the top organic result with a single keystroke.


## 📥 Installation

### Windows

```text
1. Download or Clone Repository
2. Open Brave Browser
3. Go to brave://extensions
4. Enable Developer Mode
5. Click Load Unpacked
6. Select Extension Folder
7. Done
```

### macOS

```text
1. Download or Clone Repository
```
